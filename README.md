## 关于 LLM 输出质量门

其中三个应用（TalkCal / DayPilot / 电商脚本 Agent）都内置了同一套**双层质量门**：

1. **L1 规则校验**（确定性）：结构、字段、时长预算、重复项——硬约束先卡一道
2. **L2 质量打分**（LLM-as-Judge）：从可执行性、优先级结构、时长合理性、目标相关性打分
3. 不达标 → **自动重试**（最多 2 次），并把失败原因回传给模型重新生成
4. 网络中断 / 限流 / 输出非 JSON 同样计入重试；只有鉴权失败才直接中止
5. 全部评估过程写入 Eval 日志，**可审计**

也就是说，这些应用不是「给大模型套个壳」，而是**每一次 AI 输出都要过一道关卡，不合格就不给用户看**。
