## 技术说明

- **零 CDN、零构建、零统计埋点**。除 three.js（本地 vendor）外没有任何外部依赖。
- 视频统一 720p / 30fps / H.264 / faststart，单条 ≤8 MB；`<video>` 失败自动退回封面。
- 动效为渐进增强：JS 缺失或 `prefers-reduced-motion` 时，内容与链接照常可用。
- 页面支持 `?anim=0`（关动效）、`?shot=1`（静帧，便于长截图与 PDF）。
